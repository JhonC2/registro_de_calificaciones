# Registro de Calificaciones
## Descripción
Proyecto introductorio para practicar los temas de la clase de Lenguajes de Programación para la IA.
Utilizamos Python 3.12, entornos virtuales y gestión de dependencias con Git y GitHub.
El programa permite el ingreso de los estudiantes con sus notas, calcular la media de las notas, la nota minima y maxima de la lista de calificaciones y obtener una lista de los estudiantes aprobados y reprobados.

## Requisitos
- Python 3.12

## Crear y activar el entorno virtual
macOS:
python3.12 -m venv .venv
source .venv/bin/activate

## Ejecutar el programa
python main.py

## Tecnologías
- Python 3.12
- venv
- Git y GitHub
